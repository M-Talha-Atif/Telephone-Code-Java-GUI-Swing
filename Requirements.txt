SUBSCRIBER FACE:
Balance button to show balance.
Button Call with a textbox for minutes.
Button SMS to send message (No text Box) User will click and sms cost will be deducted
Button Connection with textbox for Kilobytes. 
Button Top up with textbox for amount.
Top-down menu with all available tariffs, clicking on one of them the user will change promotion ( Combo Box for Tariff Plan)

ADMIN FACE:
Add Subscriber Button -> brings to a screen to add a user by name, surname, number, residence, tariff plan.
Add Promotion -> brings to a screen to add a promotion detail having promotion name, call charges, message charges, data connection charges.
Show users -> brings to a screen where all users are shown with quantity consumed for each service (call, SMS and connection)

Data will be stored in JSON files.
Java Eclipse will be Used with windows Builder Swing (JFrame, JPanel, JButton)
Java SDK is 17 selected.
